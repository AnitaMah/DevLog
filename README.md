# DevLog

A personal knowledge base for programming guides, your own projects, and
imported AI chats — built with Flutter, running on Windows, macOS, and
Linux desktop.

## Features

- Organize notes into modules and submodules (e.g. "C Basics", "Unix", "Git").
- Track your own projects: status, a task checklist, and a repo link.
- Import AI chat exports (Gemini, Gemini Notebook, Claude) as notes.
- Search across modules and notes from the sidebar.
- Light/dark theme, persisted across launches.

## Getting Started

```
flutter pub get
flutter run -d windows   # or macos / linux
```

Run tests with:

```
flutter test
```
